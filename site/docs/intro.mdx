# Tutorial Intro

Let's discover **the overview in less than 5 minutes**.

## Getting Started

A payment adapter is typically composed of a set of three components of control, as illustrated in the diagram:

![Architecture](/img/j8583_connector_architecture.svg)


Incoming ISO 8583 messages are published to **Sink** with unbounded buffer.
**Netty EventLoop** is a core component, responsible for handling network events like reading, writing, and connection management.
The boss thread efficiently monitors a channel for events like — *Channel* is ready for reading, *Channel* is ready for writing,
*New connection* accepted, *Connection* closed, and so on.
When sending, worker threads pack the message into a binary format and write it to *ByteBuf*.
However, upon receipt, the worker group reads the data from *ByteBuf* (knowing the message length from the length header)
and unpacks the ISO 8583 message. **Promises cache** is used to bind a request to a response during a synchronous call.

Example of an encoded ISO 8583 message:

![Encoded message](/img/undraw_encoded_message.png)


### Publish financial request

There is a scenario of publishing financial requests and observation of key metrics. Network requests will be ignored:
```java title="/src/test/java/by/ivanta/connector/J8583ConnectorApplicationTests.java" {7,9,15-16,18}
    @Test
    @Order(1)

                .untilAsserted(
```

As a result, one request was matched with a response, two requests timed out, and one response could not be matched.

### Synchronous call with financial request

There is a scenario for sending a message and waiting for a response.
A decorator has been added to actively wait for a connection to the card network server.
```java title="/src/test/java/by/ivanta/connector/J8583ConnectorApplicationAutoConnectTests.java" {30,65-73}
    @Test
    @Order(2)
    void shouldPublishFinancialRequestWhenRestApiMethodCall() throws InterruptedException {
        var tasksCount = 5;
        var executor = Executors.newFixedThreadPool(tasksCount);
        var serverRef = new AtomicReference<J8583TcpServer>();

        for (var i = 0; i < tasksCount; i++) {
            switch (i) {
                case 4 -> {
                    var _ =
                            executor.submit(
                                    () -> {
                                        try {
                                            Thread.sleep(
                                                    Duration.ofSeconds(
                                                            j8583ConnectorProperties
                                                                    .retryCooldownSec()));
                                            serverRef.set(
                                                    new J8583TcpServer(tcpServer, messageFactory));
                                        } catch (InterruptedException e) {
                                            Thread.currentThread().interrupt();
                                        }
                                    });
                }
                default -> {
                    var _ =

    private IsoMessage restApiMethodWithBusinessContext(String pan) {
        var execution =
                new ExponentialBackOffExecution(
                        INITIAL_INTERVAL_MS, MAX_INTERVAL_MS, MAX_ELAPSED_TIME_MS);
        var connected = false;
        var waitInterval = 0L;
        do {
            connected = client.isConnected();
            waitInterval = execution.nextBackOff();
            if (!connected && waitInterval != BackOffExecution.STOP) {
                try {
                    Thread.sleep(waitInterval);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        } while (!connected && waitInterval != BackOffExecution.STOP);
        if (connected) {
            return client.publishAndBlock(createPurchaseRequest(pan, messageFactory));
        }
        throw new RuntimeException("Timeout has been reached");
    }
```
